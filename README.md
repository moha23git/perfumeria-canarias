# Perfumes Canarias

## Project description

This project consists of creating a website for an online perfume shop called **Perfumes Canarias**.

The idea is to show different perfumes and organize them into two categories to make them easier to find: designer perfumes and niche perfumes.

The website has a simple design, with light colours and elegant tones, trying to make the products the main focus.

## What does the website include?

The website is divided into several sections:

- **Home:** a short introduction to the perfume shop.
- **Designer perfumes:** a gallery with 10 perfumes from different brands.
- **Niche perfumes:** a gallery with 6 perfumes.
- **About us:** a short introduction to Perfumes Canarias.
- **Tips:** some advice on how to choose a perfume.
- **Contact:** a section to go back and explore the collections.

There is also a navigation menu to move between the different sections of the website.

## Technologies used

To create this project, I have used:

- **HTML5:** to create the structure of the website.
- **CSS3:** for the colours, sizes, layout and design.
- **Flexbox:** to organize the website elements.
- **Media queries:** to adapt the website to computers, tablets and mobile phones.
- **Font Awesome:** to add icons.

## Responsive design

The website is designed to adapt to different screen sizes.

I have used media queries to change the layout depending on the device:

- Computers.
- Tablets.
- Mobile phones.

I have also added some `hover` effects to make certain elements change slightly when the mouse moves over them.

## How to view the website

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all the images are inside the `img` folder.
4. Open the `index.html` file in your browser.
